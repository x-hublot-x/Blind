# Blind

Blind - приложение для Windows в стиле боковой панели Samsung Edge, предназначенное для выделения и закрепления областей экрана поверх всех окон, распознавания текста (OCR), аннотирования и точного определения цветов на экране.

## Основные возможности

- Боковая панель (Edge Panel): выдвижная вертикальная панель у правого края экрана с матовым оформлением и возможностью перемещения вдоль границы.
- Захват и выделение: полноэкранный захват с интерактивной рамкой изменения размера (8 маркеров) и мгновенными подсказками.
- Распознавание текста (OCR): нативное извлечение текста с вырезок и закреплённых картинок через Windows.Media.Ocr с автоматическим определением русского и английского языков и сохранением форматирования.
- Инструменты рисования: нанесение аннотаций (карандаш, стрелочка, рамка, полупрозрачный хайлайтер) с выбором цвета и пошаговой отменой действий (Ctrl+Z).
- Экранная пипетка цвета: режим точного захвата цвета с 8x увеличительной лупой, сеткой пикселей, отображением HEX/RGB кодов и мгновенным копированием в буфер обмена.
- Закрепление поверх всех окон: отображение выбранной области в режиме Always-On-Top, плавное масштабирование колесиком мыши, регулировка прозрачности (Ctrl + колесико мыши) и растягивание за края.
- Быстрые действия: копирование в буфер обмена, распознавание OCR (Ctrl+T), сохранение в файл, сброс масштаба к 100% и закрытие.
- Автозапуск: переключение автозагрузки Windows через системный реестр без прав администратора.
- Системный трей: работа в фоновом режиме с быстрым управлением из трея.

## Запуск и использование

### Запуск готового приложения
Запустите файл `Blind v1.1.exe` из раздела Releases.

### Запуск из исходного кода
1. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```
2. Запустите приложение:
   ```bash
   python main.py
   ```
